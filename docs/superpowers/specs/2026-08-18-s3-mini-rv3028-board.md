# S3-MINI-1 + RV-3028-C7 Watchy Board — Design

Status: draft, pending review
Date: 2026-08-18
Derived from: sqfmi/watchy-hardware `v2.0` branch (KiCad 5, MIT, OSHWA certified)

## Purpose

A Watchy-compatible board that pairs V3's silicon with V2's independent
timekeeping, drops the parts this project never uses, and lands on USB-C.

The ref counter needs three things the shipping revisions each get half right:

- **Time that survives without WiFi.** V3 deleted the external RTC and made the
  ESP32-S3's own 32kHz domain the only clock. A crash, a brownout or a bad OTA
  loses the time, and drift is bounded only by how often NTP is reachable. V2
  keeps a PCF8563 that counts through all of it.
- **Modern silicon.** The ESP32-PICO-D4 in V2 is old, and V2 spends ~$2 and 25
  solder joints on a CP2102 that an S3 does not need.
- **No accelerometer.** `ENABLE_ACCELEROMETER` is `false` in `settings.h` and
  `RefMenu.cpp` documents why: nothing on a play clock reads a sensor. The
  BMA423 is a part we pay for, place, and never power.

## Decisions

### D1 — ESP32-S3-MINI-1 module, not a bare ESP32-S3FN8

The module carries the 40MHz crystal, flash, RF matching and antenna, and it
comes with FCC/CE modular certification. A bare chip means designing an RF
front end and paying for standalone radio certification if the board is ever
sold. The module costs roughly $1 more than the bare part and removes the
single largest respin risk in the project.

`ESP32-S3-MINI-1` (embedded 8MB quad flash, no PSRAM). **Not** the `-N4R2`
variant: that one uses IO26 for PSRAM.

### D2 — RV-3028-C7, not the PCF8563 V2 uses

| | PCF8563 (V2) | RV-3028-C7 |
| --- | --- | --- |
| Accuracy | ~±20ppm, set by an external crystal and its load caps | ±1ppm, factory trimmed |
| Drift | ~1 min/month | ~30 s/year |
| Current | ~250nA | ~40nA |
| External crystal | required (Y1, plus the load-cap matching that sets the ±20ppm) | integrated |
| Cost | ~$0.60 + crystal | ~$2.50-3.50 |

Paying ~$2 to go from a minute a month to half a minute a year is the best
value on the board, because it is the whole reason this variant exists. It
also deletes a part (the crystal) and the tuning problem that comes with it.

The PCF8563 remains a valid fallback if the RV-3028 cannot be sourced: it is
pin-incompatible but functionally equivalent, and `RefRtc` already speaks it.

### D3 — RTC powered from +BATT, backup switchover unused

`VDD` to `+BATT`, `VSS` and `VBACKUP` to `GND`, `EVI` to `GND`. This is what
V2 already does with the PCF8563 and it keeps the clock alive independently of
the LDO.

**The I2C and INT pull-ups go to +3V3, not +BATT.** With `VDD` at up to 4.2V
the RV-3028's `VIH` is 0.7 x VDD = 2.94V, which a 3.3V bus clears, while the
S3's inputs never see more than 3.3V. Pulling the bus up to +BATT instead would
put 4.2V on S3 pins. This is the one place on the board where the obvious
simplification is wrong.

`VBACKUP` is deliberately **not** fed from +BATT. In direct switching mode the
part runs from whichever supply is higher and disables SDA (high impedance) in
the backup power state, which would break I2C on a board whose battery is
always the highest rail. If a supercap is ever added, `VBACKUP` is where it
goes.

### D4 — Buttons active-low on RTC GPIOs, nothing on a strapping pin

V1-V2 buttons are active-high because the original ESP32's `ext1` deep-sleep
wake only supports `ALL_LOW` or `ANY_HIGH`; waking on any of four buttons
forced `ANY_HIGH` and external pull-downs. The S3 adds
`ESP_EXT1_WAKEUP_ANY_LOW`, so this board uses active-low buttons with internal
pull-ups, and **the RTC interrupt joins the same `ext1` mask** — one wake
source configuration for five wake reasons, read back from the wake status.

V3 puts UP on GPIO0, the strapping pin: a held or dirty button at reset drops
the watch into the bootloader instead of the watchface. This board does not put
any button on a strapping pin. GPIO0 gets a 10k pull-up to +3V3 and a test pad,
so download mode is still forceable with a jumper.

### D5 — No 32.768kHz crystal for the S3

V2 feeds the PCF8563's CLKOUT into the ESP32 as its external 32kHz slow clock
through an attenuator (R11/R19). That whole block is deleted. With the wake
source being the RTC's own alarm and the time read over I2C on every wake, the
S3's slow-clock accuracy no longer matters — it can run on the internal RC.
This removes a part and the entire class of "firmware selected the wrong RTC
clock source and the watch drifts 5%" failures.

`CLKOUT` goes to a test pad, unloaded.

### D6 — USB-C, native USB, no bridge

USB-C 16-pin receptacle. **Two 5.1k CC pulldowns, one per CC pin** — without
them a C-to-C cable delivers no power at all, which is the single most common
failure in this swap. `D+`/`D-` to IO20/IO19, which is fixed by the silicon.
USBLC6-2P6 for ESD.

The CP2102 and the UMH3N auto-reset pair are deleted. The S3's USB-Serial/JTAG
is in ROM, so esptool can drive download mode over USB without strapping.

What is given up: the serial port now only exists while firmware runs. V2's
TX/RX/GND test points are kept so a $3 USB-serial dongle recovers a console
when firmware is wedged.

### D7 — Battery divider raised to 1M/1M

V2 uses two 100k, which draws 4.2V/200k = 21uA continuously — about 15mAh a
month out of a 200mAh cell, or 7.5% of the battery to measure the battery.
1M/1M with a 100nF cap at the tap draws 2.1uA for the same 2:1 ratio.

The ratio is unchanged on purpose: firmware's `BATT_DIVIDER 2.0f` stays
correct. The cost is source impedance — the ADC must discard its first reading
after the mux settles.

### D8 — Mechanical envelope preserved

Board outline, display position, button positions, battery connector and
mounting features stay exactly where V2 puts them, so existing cases fit. The
USB-C cutout is the only mechanical change, and the case work is tracked
separately in `2026-08-18-waterproof-case-design.md`.

**Dimension conflict to resolve before layout.** The Edge.Cuts bounding box in
V2's `Watchy.kicad_pcb` measures **33.8 x 45.96mm**. sqfmi's published figure,
and the waterproof case spec, both say **35.5 x 46.0mm**. Confirm the true
outline in KiCad before touching the case model; do not silently pick one.

### D9 — Four layers

V2 is 2-layer, 1.6mm. This board goes to 4 (signal / GND / +3V3 / signal). The
MINI-1's 65 pads plus its antenna keepout make a solid reference plane worth
the ~$1-2 per board at quantity 25, and V3 made the same call for the same
reason. Thickness stays 1.6mm so the case stack is unchanged.

## Bill of material changes from V2

**Deleted:** U1 ESP32-PICO-D4, U3 CP2102, U4 BMA423, U6 PCF8563BS, Y1 32.768kHz
crystal, AE1 SWRA117D chip antenna, Q2 UMH3N auto-reset pair, J2 Micro-USB, the
CLKOUT attenuator (R11 680k, R19 100k), and the BMA423's decoupling.

**Added:** U1 ESP32-S3-MINI-1, U6 RV-3028-C7, J2 USB-C 16-pin receptacle,
2x 5.1k CC pulldowns, USBLC6-2P6 ESD array, 10k GPIO0 pull-up, 100nF ADC filter.

**Changed:** battery divider 100k/100k to 1M/1M.

**Unchanged, carried over verbatim:** the entire e-paper block (FPC24, the
L1/Q1/D1-D4/R9 boost and its VGH/VGL/VCOM capacitors), the TP4054 charger with
its PROG resistor and status LED, the CJ2301 + MBR0530 VBUS/battery OR-ing, the
ME6211C33M5G-N LDO, the S8050 vibration motor driver with its 1N4001 flyback,
the JST battery connector, and the four tactile switches.

Net effect: roughly $6-9 per board cheaper than V2 and ~7 fewer placements,
while keeping a better clock than either shipping revision.

## Firmware impact — out of scope here, do not implement

This spec covers the board only. The firmware follow-up is a separate plan:

- `RefRtc::begin()` short-circuits to `INTERNAL` on any S3 build
  (`RefRtc.cpp:57-61`). That must become an I2C probe, with `INTERNAL` as the
  fallback when nothing answers.
- `RefRtc` needs an `RV3028` kind: address 0x52, BCD time at registers
  0x00-0x06, status/control at 0x0E-0x10.
- `RefClock.cpp:196` assumes "an S3 here means V3" for the drift budget. That
  must key off the detected chip, not the SoC.
- `board.h` needs a revision block for this board.
- The `ext1` wake mask must gain `RTC_INT` alongside the four buttons, and the
  wake handler must clear the RTC alarm flag over I2C before sleeping again —
  the interrupt is level-triggered and stays asserted until cleared, so a
  missed clear means the watch wakes in a loop until the battery is flat.

## Risks

- **Nothing here can be verified without fabricating a board.** ERC, DRC and
  netlist checks prove the design is self-consistent; they prove nothing about
  whether it works. No task may claim otherwise.
- **The RV-3028-C7 footprint is not in KiCad's standard library.** It has to be
  sourced from Micro Crystal or drawn from the datasheet and checked against a
  1:1 print before fab.
- **The MINI-1 antenna keepout** must overhang the board edge with no copper,
  no plane and no traces beneath it, on all four layers.
- **KiCad 5 to modern conversion** is one-way. The V2 files are imported into a
  new project; the upstream repo is never modified.
