# S3-MINI-1 + RV-3028-C7 Board Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw a Watchy-compatible KiCad board in `board-files/` that replaces V2's ESP32-PICO-D4 with an ESP32-S3-MINI-1 module and its PCF8563 with an RV-3028-C7, drops the CP2102 and BMA423, and lands on USB-C — keeping V2's mechanical envelope and its entire e-paper, charging and motor circuitry.

**Architecture:** V2's KiCad 5 project is imported once into a new KiCad 8+ project under `board-files/`, then edited block by block. Because a schematic cannot be unit-tested the way C++ can, the test harness is a netlist assertion script: `kicad-cli` exports the netlist to XML, and `checks/netlist_check.py` asserts the pin map, the deep-sleep-wake and ADC constraints, the CC pulldowns, the RTC power arrangement and the absence of deleted parts. Those checks are written first and fail against the imported V2 design; each schematic task turns a group of them green. ERC and DRC are the second and third gates.

**Tech Stack:** KiCad 8 or 9 (schematic, PCB, `kicad-cli`), Python 3 standard library only (`xml.etree`, `csv`) for the checks and BOM, bash for the runner. No new firmware.

**Spec:** [`docs/superpowers/specs/2026-08-18-s3-mini-rv3028-board.md`](../specs/2026-08-18-s3-mini-rv3028-board.md)

## Global Constraints

- **Module is `ESP32-S3-MINI-1`**, 65 pads, embedded 8MB quad flash. **Not** `-N4R2` — that variant consumes IO26 for PSRAM.
- **RTC is `RV-3028-C7`**, I2C address **0x52**, 8 pins: 1 CLKOUT, 2 INT, 3 SCL, 4 SDA, 5 VSS, 6 VBACKUP, 7 VDD, 8 EVI.
- **The pin map in the spec is authoritative.** Every GPIO assignment, including the pad numbers, is copied from it verbatim. Do not re-derive it.
- **Buttons and `RTC_INT` must sit on IO0-IO21** — only those are RTC GPIOs on the S3, and only RTC GPIOs can wake `ext1` from deep sleep.
- **`BATT_ADC` must sit on IO1-IO10** (ADC1). ADC2 is unusable while WiFi is on.
- **No button, and no signal other than the documented test pad, may touch a strapping pin**: IO0, IO3, IO45, IO46.
- **I2C and `RTC_INT` pull-ups go to `+3V3`, never `+BATT`.** The RV-3028 runs from `+BATT` at up to 4.2V; pulling the bus to that rail puts 4.2V on S3 inputs.
- **The mechanical envelope is frozen**: board outline, display position, the four button positions, the battery connector and all mounting features stay exactly where V2 puts them. The USB-C cutout is the only permitted mechanical change.
- **Never modify the upstream `watchy-hardware` checkout.** It is a read-only reference; all edits happen in `board-files/`.
- **Nothing in this plan can be verified on hardware.** No board has been fabricated. "Verify" means ERC clean, DRC clean, and `checks/run.sh` green. Commit messages and task reports must not imply the design is known to work.
- **Commit after every task.** Board files are large; keep the history readable.

- [ ] **Step 1: Write the check script**

```python
#!/usr/bin/env python3
"""Assert the things ERC cannot: the pin map, the deep-sleep wake and ADC
constraints, the USB-C pulldowns, the RTC supply arrangement, and that the
parts this board deletes stay deleted.

Reads the kicadxml netlist that checks/run.sh exports.

    ./checks/netlist_check.py build/netlist.xml
"""

import sys
import xml.etree.ElementTree as ET

# ESP32-S3-MINI-1 datasheet v1.7 Table 3-1. Pad number -> GPIO name.
MINI1_PADS = {
    4: "IO0", 5: "IO1", 6: "IO2", 7: "IO3", 8: "IO4", 9: "IO5", 10: "IO6",
    11: "IO7", 12: "IO8", 13: "IO9", 14: "IO10", 15: "IO11", 16: "IO12",
    17: "IO13", 18: "IO14", 19: "IO15", 20: "IO16", 21: "IO17", 22: "IO18",
    23: "IO19", 24: "IO20", 25: "IO21", 26: "IO26", 27: "IO47", 28: "IO33",
    29: "IO34", 30: "IO48", 31: "IO35", 32: "IO36", 33: "IO37", 34: "IO38",
    35: "IO39", 36: "IO40", 37: "IO41", 38: "IO42", 39: "TXD0", 40: "RXD0",
    41: "IO45", 44: "IO46", 45: "EN",
}
MINI1_GND_PADS = {1, 2, 42, 43} | set(range(46, 66))
MINI1_VDD_PAD = 3

# Only IO0-IO21 are RTC GPIOs, so only they can wake ext1 from deep sleep.
RTC_GPIOS = {"IO%d" % n for n in range(0, 22)}
# ADC1 only. ADC2 is unavailable while WiFi is running.
ADC1_GPIOS = {"IO%d" % n for n in range(1, 11)}
# Strapping pins: nothing but the documented GPIO0 test pad may touch these.
STRAPPING = {"IO0", "IO3", "IO45", "IO46"}

MCU = "U1"
RTC = "U6"

# The spec's pin map, verbatim.
PIN_MAP = {
    "BTN_MENU": "IO4",
    "BTN_BACK": "IO5",
    "BTN_UP": "IO6",
    "BTN_DOWN": "IO7",
    "RTC_INT": "IO8",
    "BATT_ADC": "IO9",
    "SCL": "IO11",
    "SDA": "IO12",
    "VIB_PWM": "IO17",
    "USB_DM": "IO19",
    "USB_DP": "IO20",
    "EPD_SCK": "IO47",
    "EPD_CS": "IO33",
    "EPD_DC": "IO34",
    "EPD_MOSI": "IO48",
    "EPD_RST": "IO35",
    "EPD_BUSY": "IO36",
}
BUTTON_NETS = ["BTN_MENU", "BTN_BACK", "BTN_UP", "BTN_DOWN"]

# RV-3028-C7 pin numbers, datasheet section "Pin description".
RV3028 = {"CLKOUT": 1, "INT": 2, "SCL": 3, "SDA": 4, "VSS": 5,
          "VBACKUP": 6, "VDD": 7, "EVI": 8}

BANNED_VALUES = ["ESP32-PICO-D4", "CP2102", "BMA423", "PCF8563"]


def load(path):
    root = ET.parse(path).getroot()
    comps = {}
    for c in root.findall("./components/comp"):
        comps[c.get("ref")] = (c.findtext("value") or "").strip()
    nets = {}
    for n in root.findall("./nets/net"):
        name = n.get("name") or ""
        # KiCad prefixes local labels with the sheet path; keep the leaf.
        name = name.rsplit("/", 1)[-1]
        nodes = [(node.get("ref"), int(node.get("pin")))
                 for node in n.findall("node")
                 if node.get("pin").isdigit()]
        nets.setdefault(name, []).extend(nodes)
    return comps, nets


def pads_on(nets, net, ref):
    return sorted(p for r, p in nets.get(net, []) if r == ref)


def net_of(nets, ref, pad):
    for name, nodes in nets.items():
        if (ref, pad) in nodes:
            return name
    return None


def resistor_between(comps, nets, net_a, net_b):
    """Refdes of any resistor with one pad on net_a and the other on net_b."""
    found = []
    for ref in (r for r, _ in nets.get(net_a, []) if r.startswith("R")):
        others = {n for n, nodes in nets.items()
                  if any(r == ref for r, _ in nodes) and n != net_a}
        if net_b in others:
            found.append(ref)
    return found


def check_pin_map(comps, nets):
    bad = []
    for net, gpio in PIN_MAP.items():
        pads = pads_on(nets, net, MCU)
        if not pads:
            bad.append("net %s has no connection to %s" % (net, MCU))
            continue
        got = {MINI1_PADS.get(p, "pad%d" % p) for p in pads}
        if gpio not in got:
            bad.append("net %s is on %s, spec says %s" %
                       (net, ",".join(sorted(got)), gpio))
    return bad


def check_wake_capable(comps, nets):
    bad = []
    for net in BUTTON_NETS + ["RTC_INT"]:
        for pad in pads_on(nets, net, MCU):
            gpio = MINI1_PADS.get(pad, "pad%d" % pad)
            if gpio not in RTC_GPIOS:
                bad.append("%s is on %s, which is not an RTC GPIO and cannot "
                           "wake ext1 from deep sleep" % (net, gpio))
    return bad


def check_adc1(comps, nets):
    bad = []
    pads = pads_on(nets, "BATT_ADC", MCU)
    for pad in pads:
        gpio = MINI1_PADS.get(pad, "pad%d" % pad)
        if gpio not in ADC1_GPIOS:
            bad.append("BATT_ADC is on %s, which is ADC2 and unusable with "
                       "WiFi on" % gpio)
    return bad


def check_strapping(comps, nets):
    bad = []
    for pad, gpio in MINI1_PADS.items():
        if gpio not in STRAPPING:
            continue
        net = net_of(nets, MCU, pad)
        if net is None:
            continue
        allowed = {"TP_BOOT", "+3V3"} if gpio == "IO0" else set()
        if net not in allowed:
            bad.append("strapping pin %s is on net %s" % (gpio, net))
    return bad


def check_usb_c(comps, nets):
    bad = []
    for cc in ("CC1", "CC2"):
        rs = resistor_between(comps, nets, cc, "GND")
        if not rs:
            bad.append("%s has no pulldown to GND; a C-to-C cable will "
                       "deliver no power" % cc)
            continue
        for r in rs:
            if "5.1k" not in comps.get(r, "").lower().replace(" ", ""):
                bad.append("%s pulldown %s is %r, expected 5.1k" %
                           (cc, r, comps.get(r)))
    return bad


def check_rtc(comps, nets):
    bad = []
    if RTC not in comps:
        return ["%s is missing from the design" % RTC]
    if "RV-3028" not in comps[RTC].upper().replace(" ", ""):
        bad.append("%s is %r, expected RV-3028-C7" % (RTC, comps[RTC]))
    expect = {"VDD": "+BATT", "VSS": "GND", "VBACKUP": "GND", "EVI": "GND",
              "INT": "RTC_INT", "SDA": "SDA", "SCL": "SCL"}
    for pin, want in expect.items():
        got = net_of(nets, RTC, RV3028[pin])
        if got != want:
            bad.append("%s pin %s is on %s, spec says %s" %
                       (RTC, pin, got, want))
    return bad


def check_pullups(comps, nets):
    bad = []
    for net in ("SDA", "SCL", "RTC_INT"):
        if not resistor_between(comps, nets, net, "+3V3"):
            bad.append("%s has no pull-up to +3V3" % net)
        if resistor_between(comps, nets, net, "+BATT"):
            bad.append("%s is pulled up to +BATT; at 4.2V that overdrives the "
                       "S3 input, it must pull up to +3V3" % net)
    return bad


def check_mcu_power(comps, nets):
    bad = []
    if MCU not in comps:
        return ["%s is missing" % MCU]
    if "S3-MINI-1" not in comps[MCU].upper().replace(" ", ""):
        bad.append("%s is %r, expected ESP32-S3-MINI-1" % (MCU, comps[MCU]))
    if net_of(nets, MCU, MINI1_VDD_PAD) != "+3V3":
        bad.append("%s pad 3 (3V3) is not on +3V3" % MCU)
    stray = [p for p in MINI1_GND_PADS
             if net_of(nets, MCU, p) not in (None, "GND")]
    if stray:
        bad.append("%s GND pads on a non-GND net: %s" % (MCU, stray))
    return bad


def check_deleted(comps, nets):
    bad = []
    for ref, value in comps.items():
        for banned in BANNED_VALUES:
            if banned.upper() in value.upper():
                bad.append("%s is %s; this board deletes that part" %
                           (ref, value))
    return bad


CHECKS = [
    ("pin map", check_pin_map),
    ("deep-sleep wake pins", check_wake_capable),
    ("battery ADC on ADC1", check_adc1),
    ("strapping pins", check_strapping),
    ("USB-C CC pulldowns", check_usb_c),
    ("RV-3028-C7 wiring", check_rtc),
    ("bus pull-ups", check_pullups),
    ("MCU power", check_mcu_power),
    ("deleted parts", check_deleted),
]


def main(argv):
    if len(argv) != 2:
        print("usage: netlist_check.py <netlist.xml>", file=sys.stderr)
        return 2
    comps, nets = load(argv[1])
    failures = 0
    for title, fn in CHECKS:
        problems = fn(comps, nets)
        if problems:
            failures += len(problems)
            print("FAIL %s" % title)
            for p in problems:
                print("       %s" % p)
        else:
            print("ok   %s" % title)
    print()
    print("%d problem(s)" % failures)
    return 1 if failures else 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

- Pin 7 `VDD` -> `+BATT`
- Pin 5 `VSS` -> `GND`
- Pin 6 `VBACKUP` -> `GND`
- Pin 8 `EVI` -> `GND`
- Pin 3 `SCL` -> `SCL`
- Pin 4 `SDA` -> `SDA`
- Pin 2 `INT` -> `RTC_INT`

100nF decoupling from `+BATT` to `GND` beside the part.

`VDD` on `+BATT` rather than `+3V3` is deliberate: it keeps the clock running independently of the LDO, which is the entire reason this board exists. `VBACKUP` is tied to `GND`, not to a rail — in direct switching mode the part runs from whichever supply is higher and disables SDA in the backup state, which on a board whose battery is always the highest rail would break I2C. - [ ] **Step 2: Write the BOM generator**

```python
#!/usr/bin/env python3
"""Group the netlist's components into a fab-ready BOM.

    ./checks/make_bom.py build/netlist.xml fab/BOM.csv
"""

import csv
import sys
import xml.etree.ElementTree as ET


def natural(ref):
    head = ref.rstrip("0123456789")
    tail = ref[len(head):]
    return (head, int(tail) if tail else 0)


def main(argv):
    if len(argv) != 3:
        print("usage: make_bom.py <netlist.xml> <out.csv>", file=sys.stderr)
        return 2
    root = ET.parse(argv[1]).getroot()
    groups = {}
    for c in root.findall("./components/comp"):
        ref = c.get("ref")
        value = (c.findtext("value") or "").strip()
        footprint = (c.findtext("footprint") or "").strip()
        # Logos, test points and other fiducials are not ordered parts.
        if ref.startswith(("TP", "G", "REF", "LOGO", "FID")):
            continue
        groups.setdefault((value, footprint), []).append(ref)
    rows = []
    for (value, footprint), refs in groups.items():
        refs.sort(key=natural)
        rows.append({
            "Quantity": len(refs),
            "Value": value,
            "Footprint": footprint.split(":")[-1],
            "Designators": ",".join(refs),
        })
    rows.sort(key=lambda r: (r["Footprint"], r["Value"]))
    with open(argv[2], "w", newline="") as fh:
        writer = csv.DictWriter(
            fh, fieldnames=["Quantity", "Value", "Footprint", "Designators"])
        writer.writeheader()
        writer.writerows(rows)
    print("%d line items, %d placements"
          % (len(rows), sum(r["Quantity"] for r in rows)))
    return 0


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```

8. The four switches, the FPC connector and the battery connector sit at V2's coordinates.
9. The USB-C cutout position is recorded for the case model.

## Out of scope

**Firmware.** This plan produces board files only. The firmware work — probing
I2C for the RTC instead of inferring it from the SoC, an RV-3028 driver in
`RefRtc`, the `ext1` wake mask gaining `RTC_INT`, clearing the alarm flag
before sleeping, a `board.h` revision block, and discarding the first ADC
reading — is a separate plan against the "Firmware impact" section of the spec.
It cannot be verified without a fabricated board either, but it can at least be
compiled and host-tested, which this plan cannot claim for anything it touches.

**The case.** `docs/superpowers/specs/2026-08-18-waterproof-case-design.md` owns
the enclosure. Task 9 records the outline dimension conflict and Task 12 records
the USB-C cutout position for it; nothing here modifies the case model.
